{{- /* Responsive body image. Resolves a single logical source to the best available tiered set (see partials/responsive-image.html): pre-generated size-ladder variants -> width-descriptor srcset; a single pre-generated output -> plain img; otherwise build-time AVIF generation. The image is wrapped in a link to the full-resolution (100%) variant unless link="false". src required. Source/base path relative to the page (e.g. "media/photo.avif"). Matching is by stem; the extension only locates the file. alt optional. Alt text. title optional. Hover-tooltip text (the title attribute). Defaults to alt when unset. Not a substitute for alt: title is shown only on mouse hover, ignored on touch/keyboard, and not announced by screen readers by default. rotate optional. Degrees to rotate the image clockwise for display ("90", "180", "270"), via a CSS transform. A 90/270 turn also swaps the reserved layout box (from the image's intrinsic dimensions) so it occupies the correct space rather than overflowing; 180 rotates in place. sizes optional. Rarely needed. Defaults to the content-column layout (full width on mobile, capped at the content column on desktop). Override only for unusual layouts (e.g. a floated thumbnail). sizes="auto" is intentionally not the default: body images are styled max-width:100% with no explicit width, which makes auto-sizing pick a too-small file. class optional. Class on the . loading optional. "lazy" (default) or "eager". fetchpriority optional. e.g. "high". link optional. "true" (default) wraps the image in a link to the 100% variant; "false" emits a bare . pixelated optional. "true" enlarges the image as crisp blocks rather than smoothing it (image-rendering: pixelated), for pixel-level comparisons. Lets a figure ship at native scale and be magnified by CSS, which costs nothing on the wire and follows the reader's layout and device pixel ratio instead of a zoom chosen at build time. Normally paired with pin="true", since a resampled srcset rung would defeat it. Handled by responsive-img, so every image surface that uses that partial gets it; the rule is emitted once per page, only where used. pin optional. "true" pins the delivered encode: the LOW/MED/HI quality toggle skips this image and it always renders as encoded. Use for figures whose subject *is* the difference between the encodes — put `foo.avif` and `foo-hq.avif` side by side without pinning and the toggle swaps the first for the second, making both identical. Also drops the full-size link's own hq target, so the linked image matches what was on the page. Default "false". widths optional. Space-separated widths for the build-time generation fallback. Default "200 400 600 800". */ -}} {{- $src := .Get "src" | default (.Get 0) -}} {{- $alt := .Get "alt" | default "" -}} {{- $class := .Get "class" -}} {{- $loading := .Get "loading" | default "lazy" -}} {{- $fetchpriority := .Get "fetchpriority" -}} {{- /* Default matches the theme layout: html font-size is 62.5% (1rem = 10px), .container is 90rem with 2rem side padding, so the content column tops out at (90 - 4) * 10 = 860px; padding is 40px. Below 768px images are full width. Expressed in px because font-relative units in `sizes` are unreliable with the preload scanner. */ -}} {{- $sizes := .Get "sizes" | default "(max-width: 768px) 100vw, min(100vw - 40px, 860px)" -}} {{- $link := not (in (slice "false" "0" "") (.Get "link" | default "true")) -}} {{- $pin := in (slice "true" "1") (.Get "pin" | default "false") -}} {{- $pixelated := in (slice "true" "1") (.Get "pixelated" | default "false") -}} {{- $r := partial "responsive-img.html" (dict "page" $.Page "src" $src "alt" $alt "title" (.Get "title" | default $alt) "rotate" (.Get "rotate" | default "") "sizes" $sizes "class" $class "loading" $loading "fetchpriority" $fetchpriority "widths" (.Get "widths" | default "200 400 600 800") "pin" $pin "pixelated" $pixelated "genNative" $link) -}} {{- if not $r.primary -}} {{- warnf "image: no file found for %q" $src -}} {{- else if and $link $r.full -}} {{ $r.img | safeHTML }} {{- else -}} {{ $r.img | safeHTML }} {{- end -}}
