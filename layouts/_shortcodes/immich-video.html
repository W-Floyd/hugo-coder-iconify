{{- /* immich-video: click-to-load video from a public Immich shared link. Nothing but a small poster is fetched until the reader clicks, then it streams via Immich's realtime-transcode HLS (the theme's minimal hls.js build from `make hls`, loaded on click; Immich's variant playlists need ?slug=, which native HLS players can't add), falling back to the stored MP4 where hls.js is unsupported or errors. The HLS rung follows the site's low/med/hi toggle (coder.js, `imagequality`): 480p / 720p / 1080p, taking the cheapest codec hls.js can play at that size. Flipping the toggle mid-playback moves an HLS video to the nearest level at the next segment boundary (hls.js nextLevel); the MP4 fallback is one file and can't change. Doesn't work with params.csp: that policy has no media-src and blocks the inline script. Playback uses a custom control bar (play, seek, time, mute, quality, fullscreen). The wrapper's data-figure-item and closing make it a {{< figures >}} item. A hidden data-rimg marker image makes coder.js show the toggle on pages whose only managed image is a video; the poster itself is deliberately not marked, since coder.js would restore its stashed src and fight the poster switch. The card shows an estimated download size for the active tier, computed at build time from Immich's playlist bitrates and the asset duration. Every instance carries the style and script inside its own wrapper div (the script runs once, behind a window flag). Deliberately stateless: a once-per-page gate via Page.Store/Scratch is unreliable under `hugo serve` (content is also rendered for summaries/metadata, and the gate fires on the wrong pass), and {{< figures >}} keeps only recognised items so anything outside the div is dropped. Give videos in a figure a `ratio` so figures can size them. url required. Shared-link URL, https://host/share//photos/, or https://host/share/ for a single-asset share; the id is then looked up at build time, so the build fails if Immich is unreachable. muted optional. "true" starts the video muted. poster optional. Pin the Immich poster size: "preview" (1440px) or "thumbnail" (250px, ~10x smaller). Unset, the poster follows the quality toggle: low = thumbnail, med/hi = preview (Immich's "fullsize" just redirects to preview for videos). ratio optional. Poster aspect ratio (e.g. "9/16") to reserve space and avoid layout shift while the poster loads. */ -}} {{- $m := findRESubmatch `^(https?://[^/]+)/share/([^/?#]+)(?:/photos/([^/?#]+))?` (.Get "url") 1 -}} {{- if not $m }}{{ errorf "immich-video: url %q is not an Immich share link (%s)" (.Get "url") .Position }}{{ end -}} {{- $m = index $m 0 -}} {{- $server := index $m 1 }}{{ $slug := index $m 2 }}{{ $id := index $m 3 -}} {{- $muted := eq (.Get "muted") "true" -}} {{- /* The share's asset list gives the duration for the size estimate (omitted if Immich is unreachable) and, when the URL names no asset, the asset id. */ -}} {{- $assets := slice -}} {{- with try (resources.GetRemote (printf "%s/api/shared-links/me?slug=%s" $server $slug)) -}} {{- with .Value }}{{ $assets = (.Content | transform.Unmarshal).assets }}{{ end -}} {{- end -}} {{- if and $slug (not $id) -}} {{- if eq (len $assets) 1 }}{{ $id = (index $assets 0).id -}} {{- else }}{{ errorf "immich-video: share %q has %d assets, name one with /photos/ (%s)" $slug (len $assets) .Position }}{{ end -}} {{- end -}} {{- $dur := 0.0 -}} {{- range $assets }}{{ if eq .id $id }}{{ $dur = div (float .duration) 1000 }}{{ end }}{{ end -}} {{- $base := printf "%s/api/assets/%s" $server $id -}} {{- $bw := dict -}} {{- with try (resources.GetRemote (printf "%s/video/stream/main.m3u8?slug=%s" $base $slug)) -}} {{- with .Value -}} {{- range findRESubmatch `BANDWIDTH=(\d+),RESOLUTION=(\d+)x(\d+)` .Content -}} {{- $b := float (index . 1) -}} {{- $k := string (int (math.Min (float (index . 2)) (float (index . 3)))) -}} {{- if or (not (isset $bw $k)) (lt $b (index $bw $k)) }}{{ $bw = merge $bw (dict $k $b) }}{{ end -}} {{- end -}} {{- end -}} {{- end -}}
